1. API Endpoints & Contracts:
   - POST /api/reservations/ingest: Receives reservation JSON payload (supplierId, reservationId, roomId, checkIn, checkOut, price, updatedAtUtc).
   - GET /api/reservations/stats/{supplierId}: Returns metrics for a specific supplier (total ingested vs. total throttled requests).

2. Deduplication & Upsert Logic (SQLite + Dapper):
   - If an exact reservation already exists with identical details -> skip writing and respond indicating no change.
   - If the same reservationId arrives with newer/different details -> update the existing record (Upsert).

3. Lossless Queuing, Throttling & Rate Limiting:
   - Rolling 60-second window rate limiter per supplier (max 100 requests/minute).
   - If a supplier exceeds 100 requests in the window, throttle/reject further requests (or queue them losslessly via a Channel + Background Worker with retry mechanism, tracking throttled counts for the stats endpoint).
